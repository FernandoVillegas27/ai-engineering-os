# AI Engineering OS

Plataforma de ingeniería asistida por IA para desarrollar software con múltiples agentes, skills, herramientas y modelos sin quedar acoplado a un único proveedor o IDE.

## Objetivo

Construir un ecosistema donde:

- los agentes tengan roles especializados;
- las skills aporten conocimiento tecnológico bajo demanda;
- los agentes puedan descubrir capacidades de otros agentes;
- la memoria persista entre sesiones y proyectos;
- se integren herramientas mediante MCP;
- Cursor, Claude Code, Codex, OpenCode y otros runtimes puedan utilizar el mismo ecosistema;
- las decisiones de ingeniería sean reproducibles, verificables y portables.
